# 🚗 DRIVE DEALS — دليل تحديث البيانات والمحتوى
### Plain-English Guide for Updating Items & Banner Data

مرحباً بك! هذا الدليل مُعدّ بلغة بسيطة ومباشرة لمساعدتك في إضافة وتعديل محتويات موقع **Drive Deals** (الأفلام، المسلسلات، الألعاب، وشريط العروض العلوي) عن طريق ملفات **Excel** فقط دون الحاجة لأي خبرة برمجية.

---

## 📌 الفكرة العامة باختصار (The Big Picture)

الموقع يقرأ كل شيء تلقائياً من ملفين رئيسيين في كل عملية تحديث:

| ما تريده | أين تكتبه | أين تضع الصور | الأمر الذي تشغله |
|---|---|---|---|
| **الأفلام والمسلسلات والألعاب** | `source.xlsx` (المجلد الرئيسي) | داخل مجلد `assets/` | `npm run excel-to-json` |
| **البانر المتحرك بالأعلى** | `banner/source.xlsx` (مجلد banner) | داخل مجلد `banner/assets/` | `npm run banner-excel-to-json` |

> [!CAUTION]
> **تحذير هام جداً:** لا تقم بتعديل ملف `data.json` أو `banner/data.json` يدوياً أبداً! فهما ملفان يتم إنشاؤهما تلقائياً من الإكسيل، وأي تعديل يدوي فيهما سيتم مسحه واستبداله عند تشغيل أمر التحديث.

---

## 🎬 أولاً: كيفية إضافة أو تعديل عناصر الموقع (الأفلام والمسلسلات والألعاب)

### الخطوة 1: وضع الصورة
1. احفظ صورة البوستر بصيغة `.jpg` أو `.png`.
2. ضع الصورة في مجلد القسم المناسب داخل `assets/`:
   - أفلام عربي ⬅️ `assets/arabic-films/`
   - أفلام أجنبي ⬅️ `assets/foreign-films/`
   - سلاسل أفلام أجنبي ⬅️ `assets/foreign-film-series/`
   - مسلسلات عربي ⬅️ `assets/arabic-series/`
   - مسلسلات أجنبي ⬅️ `assets/foreign-series/`
   - مسلسلات تركي ⬅️ `assets/turkish-series/`
   - مسلسلات كوري ⬅️ `assets/korean-series/`
   - أفلام كرتون ⬅️ `assets/cartoon-films/`
   - مسلسلات كرتون ⬅️ `assets/cartoon-series/`
   - أفلام هندي ⬅️ `assets/indian-films/`
   - أنمي ⬅️ `assets/anime/`
   - ألعاب ⬅️ `assets/games/`

### الخطوة 2: فتح ملف `source.xlsx`
1. افتح ملف `source.xlsx` في المجلد الرئيسي بواسطة برنامج Excel.
2. اختر الشيت (Sheet) الخاصة بالقسم من الأسفل (مثال: شيت `games` أو `arabic-films`).
3. أضف سطراً جديداً في الأسفل يتكون من 3 أعمدة:
   - **title**: اسم العمل بالعربي أو الإنجليزي (كما سيظهر للعميل في البحث).
   - **image**: اسم ملف الصورة كاملاً مع الامتداد (مثال: `Spider-Man.jpg`).
   - **sizeGB**: الحجم بالجيجابايت كرقم فقط (مثال: `45` أو `12.5`).
4. احفظ الملف (Save / Ctrl + S أو Cmd + S).

### الخطوة 3: تحديث الموقع
افتح نافذة الأوامر (Terminal) في مجلد المشروع واكتب:
```bash
npm run excel-to-json
```
ستظهر لك رسالة تأكيد بعدد الأقسام والعناصر المحدثة (مثال: `Wrote 12 categories (3363 items) to data.json`).

---

## 🌟 ثانياً: كيفية تحديث البانر العلوي (الألعاب/العروض المميزة)

البانر هو شريط الصور العريض المتحرك في أعلى الموقع.

### الخطوة 1: وضع صورة البانر
- احفظ الصورة العريضة داخل المجلد:
  `banner/assets/`
  *(مثال: `banner/assets/Mortal Shell II.jpg`)*

### الخطوة 2: فتح ملف `banner/source.xlsx`
1. افتح الملف الموجود داخل مجلد البانر:
   `banner/source.xlsx`
2. في شيت `banner`، ستجد الأعمدة الثلاثة:
   - **title**: عنوان العرض أو اللعبة (مثال: `The Blood of Dawnwalker`).
   - **image**: اسم ملف الصورة الموجود في `banner/assets/` (مثال: `The Blood of Dawnwalker.jpg`).
   - **sizeGB**: الحجم بالجيجابايت (مثال: `42.03`).
3. احفظ ملف الإكسيل.

### الخطوة 3: تشغيل أمر تحديث البانر
في نافذة الأوامر (Terminal)، اكتب:
```bash
npm run banner-excel-to-json
```
ستظهر لك رسالة نجاح مثل:
`Wrote 4 banner item(s) to banner/data.json`

## 💻 ثالثاً: تشغيل الموقع ومعاينته على جهازك (Localhost)

لمعاينة الموقع على متصفحك:

1. شغل السيرفر المحلي بكتابة الأمر:
   ```bash
   npx serve . -l 3001
   ```
2. افتح المتصفح على الرابط:
   [http://localhost:3001](http://localhost:3001)
3. لإيقاف السيرفر عندما تنتهي: اضغط في نافذة الأوامر على `Ctrl + C`.

## ⚠️ قواعد ذهبية لتفادي الأخطاء (Golden Rules)

1. **تطابق اسم الصورة 100%**:
   - الاسم المكتوب في عمود `image` بالإكسيل يجب أن يطابق اسم الملف في المجلد حرفياً مع الامتداد.
   - مثال: لو اسم الملف `Batman.jpg` لا تكتب في الإكسيل `batman.jpg` أو `Batman.png`.
2. **الحجم أرقام فقط**:
   - في عمود `sizeGB`، اكتب `15` أو `8.2`.
   - **لا** تكتب `15 GB` أو `15 جيجا`.
3. **لا تعدل السطر الأول في الإكسيل**:
   - السطر الأول يحتوي على عناوين الأعمدة (`title | image | sizeGB`)، لا تحذفه أو تغير تسمياته.
   - البيانات تبدأ دائماً من السطر الثاني.
4. **احتفظ بنسخة احتياطية**:
   - قبل تعديل أو إضافة مئات الصفوف، خذ نسخة احتياطية من ملف الإكسيل كأمان.

## 🛠️ حل المشاكل الشائعة (Troubleshooting)

| المشكلة | السبب المحتمل | الحل |
|---|---|---|
| **صورة البانر تظهر شاشة فارغة / سوداء** | اسم الصورة في `banner/source.xlsx` لا يطابق الصورة الموجودة داخل `banner/assets/` | تأكد من وجود ملف الصورة بنفس الاسم والامتداد في `banner/assets/` ثم أعد تشغيل `npm run banner-excel-to-json`. |
| **صورة الفيلم تظهر عليها علامة "غير متاحة"** | الصورة غير موجودة في مجلد القسم أو اسمها مختلف | ضع الصورة داخل `assets/<category>/` بالاسم المطابق لعمود `image`. |
| **العنصر لا يظهر على الموقع بعد إضافته** | لم تقم بتشغيل أمر التحديث، أو لم تقم بتحديث صفحة المتصفح | شغل `npm run excel-to-json` ثم اضغط `Refresh` في المتصفح. |
| **أمر التحديث يظهر تحذيرات (Warnings)** | هناك صور مفقودة تم ذكرها في الإكسيل ولكن لم توضع في المجلد | اقرأ اسم الصورة في التحذير وضعها في المجلد المناسب. |
