# أدوات تعبئة التفاصيل — tools/

المشروع ده بيبني صفحات التفاصيل لكل عنصر في المكتبة. البيانات
المصدر بتاعها `data.json` (المكتبة) + `details/<category>.json`
(التفاصيل). السكربتات هنا بتجيب التفاصيل من **API مجانية** من غير
أي backend ولا مفاتيح.

## الفكرة

```bash
npm run fill:games    # 1130 لعبة — Steam (فيه مواصفات التشغيل)
npm run fill:media    # 2241 فيلم/مسلسل/أنمي — AniList/TVMaze/Wikipedia
npm run details:report   # تقرير التغطية
npm run details:validate # فحص إن كل سجل بيترندر صح
npm test              # اختبارات المطابقة والمواصفات
```

## المصادر المستخدمة

| المزود | الفئات | ليه |
|---|---|---|
| **Steam Store API** | `games` | المصدر الوحيد المجاني اللي فيه **مواصفات التشغيل** (دنيا + موصى بها). بيدّي واجهة عربية للمواصفات. |
| **Wikipedia (ألعاب)** | `games` | ثلث الألعاب مش على Steam (حصريات، إصدارات قديمة اتشالت من المتجر، Epic/GOG). الـ infobox بتاع الألعاب فيه المطور والناشر والمنصات والمحرك والسلسلة — من غير مواصفات، وده مسجّل في `needsRequirements`. |
| **SystemRequirementsLab** | `games` | موقع متخصص في المواصفات فيه **~19,000 لعبة**، وبيلقط الألعاب اللي Steam و Wikipedia مش عارفينها (حقّان وإصدارات قديمة). الـsitemap بتاعه (3.5MB) بيتقرأ مرة واحدة ويتبني منه فهرس، فالبحث عن عنوان محلي مش بيخبط السيرفر. البيانات inline في الـHTML. |
| **PCGamingWiki** | `games` | ويكي مجتمعي للألعاب، API عامة ومفيش مفتاح. مواصفاته في قالب `{{System requirements}}` بحقول مسمّاة، فبتتقري **بالضبط** من غير ما ن scrape تنسيق الصفحة. وبيوصل لإصدارات قديمة مش على أي متجر. |
| **Wikidata** | كل القوايم | بيدّي الحقول المنظّمة اللي المقالات بتفوّتها: **التصنيف، المخرج، الأبطال، سنة الإصدار، المنصات** — و**بالعربي**. "تصويب من منظور الشخص الأول" و"روكستار نورث" بدل النص الإنجليزي. وبيحل عناوين يابانية رومانية (`AnsatsuKyoushits` → Assassination Classroom) عن طريق الـaliases. |
| **AniList** | `anime` | بيانات الأنمي منظمة: حلقات، ستوديو، تصنيف، ملخص بدون حرق (بيقطع عند `SPOILER:`). |
| **TVMaze** | `*-series` | المسلسلات: تاريخ العرض، الشبكة، التصنيف، مدة الحلقة. |
| **Wikipedia (وسط الترشيح)** | كل الـ media | بيغطي العناوين العربية والتركية والهندية اللي الـ APIs المنظمة مش بتغطّيها. الفقرة الأولى (lead) ملخص بدون حرق بحكم العُرف. |
| **Wikipedia (المجموعات)** | `foreign-film-series` وغيره | رفوف زي `Harry Potter collection` و `300 1+2` هي سلسلة أفلام مش فيلم واحد — بتترجع لمقال السلسلة نفسه. |

### لغات ويكيبيديا

ال-provider بيدوّر في أكتر من ويكي حسب لغة العنوان، لأن Films كتير
مالهاش مقال إنجليزي مفيد: `El Cuerpo` موجود في الاسباني، و
`المصيد` في العربي. Guard "هل ده فيلم فعلاً؟" بيتعرّف على الكلمة
في كل اللغة (`película`, `série`, `Fernsehserie`, `фильм`, `فيلم`...).

صفحات الـ disambiguation بتتقري بعد كده: `El cuerpo` ممكن يعني فيلم
أمريكي و فيلم إسباني و رواية — فالموضوع بيتتبع من صفحتها لصفحة
الفيلم الصح.

## مبدأ التصميم: **ما في تخمين**

- أي عنصر ما بيتطابقش فوق حد الثقة (**floor**) بيتسجل كـ **miss** في
  `.cache/` — **مش** بيتكمل بمعلومة مخمّنة.
- صفحة غلط أسوأ بكتير من صفحة فاضية، عشان المستخدم مش بيقدر يشوف
  الخطأ.
- العناصر اللي اتبحثت فيها يدوياً (`source` مش من الـ auto) **مش**
  بتتكتب فوقها.
- كل سكربت **قابل للاستئناف** عن طريق كاش `.cache/` — لو وقف في
  النص، يكمل من مكانه.

### حراسة المحتوى (content guards)

التطابق بالاسم وحده مش كفاية. كل guard دي existed عشان لقيت خطأ
حقيقي في البيانات:

| الحارس | يمنع إيه |
|---|---|
| `isMediaPage` | `11.11` → صفحة numerology، `122` → صفحة العدد |
| `isDisambiguationText` | `The Brothers` → صفحة "may refer to" |
| نوع من أول 250 حرف | `Aladdin` (فيلم) → مصنّف مسلسل لأن مقالته بتذكر مسلسل متحرك 1994 |
| `coversAllTokens` | `Assassins.Creed.Valhalla` → مقال السلسلة مش اللعبة |
| `fitsCategory` | فيلم على رف مسلسلات |
| `isFilmSeries` | `Resident Evil Collection` → لعبة فيديو مش أفلام |
| `isPlausibleName` | **كل** الأسماء العربية (مفيش حرف كبير) |

كل سجل من الكاش بيتعاد فحصه بالـguards قبل إعادة استخدامه، فأي
حاجة كانت مخزنة قبل إضافة guard مش بتتنشر.

`tools/prune-details.js` بيحذف السجلات القديمة، و
`tools/drop-stale.js` بيحذف السجلات اللي مصدرها مش مسموح به في
قايمتها.

## المطابقة — `tools/lib/match.js`

عناوين المكتبة جاية من أسماء الملفات، فملوثة:

```
"3 Idiots (2009)  [720p]"          → 3 Idiots
"Crash.Bandicoot.N.Sane.Trilogy-CODEX" → Crash Bandicoot N Sane Trilogy
"Dark Pals - The 1st Floor"        → Dark Pals The 1st Floor  (1st تفضل ملزومة)
"المؤسس عثمان" ↔ "المؤسس عثمان (الموسم الرابع)"
"cukur" ↔ "Çukur"                  (تركي)
"Blade Runner 2049" ≠ "Blade Runner" (الرقم جزء من الاسم)
```

المطابقة token-based (Dice coefficient) +:
- إزالة suffixes الـ scene (جودة، كودك، لغة)
- تطبيع الأرقام الرومانية (`ROME II` = `Rome 2`)
- طيّ الرموز (`™`, `®`)
- معالجة الترقيم العربي (`الازرق` = `الأزرق`, `جنية` = `جنيه`)
- رفض DLC/bundles (`Minecraft` ≠ `Minecraft Dungeons II`)
- رفض الـ sequels (`Dune` ≠ `Dune: Part Two`)
- char-level fallback للعربي (لأن `"السوق الحرة"` vs `"سوق حر"` مافيهاش
  tokens مشتركة كافية)

جرّب `npm run test:match` (30+ حالة، كلها real titles من المكتبة).

## مواصفات التشغيل — `tools/lib/requirements.js`

Steam بيدّي المواصفات كنص HTML واحد. الـ parser بيحوّلها لصفوف
منظمة يفهمها `item.js`:

```json
{
  "minimum":     { "os": "...", "cpu": "...", "ram": "...", "gpu": "...", "storage": "..." },
  "recommended": { "os": "...", ... }
}
```

بيتعامل مع:
- صفحات عربي بتحط **كذا حقل في سطر واحد** (بيفصلهم).
- صفحات من غير labels (fallback للترتيب الثابت بتاع Steam).
- التكرار عربي/إنجليزي لنفس الرقم (بيشيل المكرر).

جرّب `npm run test:requirements`.

### فهرس AniList المحلي

الأنمي كان أكبر ثغرة، لأن العناوين **روماني ياباني**
(`AnsatsuKyoushits`, `Re.Zero kara Hajimeru Isekai Seikatsu`) والبحث
الحي بيخمّن غلط. الحل: تنزيل الكتالوج مرة واحدة
**(.cache/anilist-index.json — 12,813 أنمي، 6,792 منهم مرادفات)**،
وضغط العنوان على **أسماء معروفة** بدل ما نتخمن.

ملاحظة: AniList بيرفض `page` أكبر من 5000، و **مش** بيدعم
`id_greater`، فالتنزيل مقسّم **على سنة العرض** — كل سنة أقل من الحد
ده. ووبين الـ3 ثواني لازم، من غيرها التنزيل بيطلع ناقص
في_DIGITALE صمت.

### مطابقة SystemRequirementsLab

الموقع مافيش عنده بحث، لكن الـsitemap بيقسم أسماء الألعاب بشكل مقروء
(`grand-theft-auto-v`). المطابقة بتتم على الـslug، مع 5 حمايات اتكتبت
كل واحدة بسبب خطأ حقيقي:

| الحارس | يمنع إيه |
|---|---|
| تغطية الكلمات | `Metal Gear Solid V` → `gears-5` |
| مطابقة الرقم | `Witcher 3` → `the-witcher` (اللعبة الأولى) |
| الرقم بلا أساس | `Crysis 1` →Series غير مرقّمة، فـ`1` بتتجاهل |
| السنة أو الموسم | `FIFA 2013` → `fifa-23` (السلسلة مرقّمة بلا أساس) |
| كلمة Part | `Deathly Hallows Part 1` → `Part 2` |
| حروف التوسعة | اللعبة نفسها بدل `-dlc` / `-soundtrack` |

**السنة بتتقبل بأشكالها:** `FIFA 2013` اسمه عندهم `fifa-13`، فالسنة
`2013` بتقبل `2013` أو `13` — بس `fifa-23` مرفوض. ولو السلسلة مرقّمة
ومفيش رقم مطابق (`Fifa 26`)، البحث **بيرفض** بدل ما يرد برقم تاني.

### الموقع كـ "قانون أسماء"

أكتر فايدة من الموقع مش المواصفات نفسها — **الاسم الصح**. المجلد
اللي في المكتبة اسمه `God.Of.War1` أو `Expedition 33`، و Wikipedia
مش عارفهم. بس أول ما الموقع يأكد إن اللعبة موجودة ويسميها صح:

| اسم المجلد | الاسم الصح | النتيجة |
|---|---|---|
| `Expedition 33` | Clair Obscur: Expedition 33 | ✅ |
| `Fifa 2013` | FIFA 13 | ✅ |
| `God.Of.War1` | God of War | ✅ |

فالصفحة اللي كانت "مواصفات بس" بقت صفحة كاملة. ولازم الـHTML
entities تتحل الأول، `Assassin&#x27;s` مش هيلاقي مقال.

### أخطر خطأ في المشروع: تصادم أسماء ملفات الكاش

```js
// غلط — بيشتغل صح على الإنجليزي، وبيدمّر العربي
id.replace(/[^\w.-]+/g, "_")
```

في JavaScript، الـ`\w` معناها `[A-Za-z0-9_]` **بس**. أي حرف عربي
أو ياباني بيتحول لشرطة سفلية، فكل العناوين العربية بتطلع بنفس
الشكل:

```
arabic-films/30 يوم في العز.jpg  →  arabic-films__arabic-films_.jpg.json
arabic-films/أحمد و أحمد.jpg      →  arabic-films__arabic-films_.jpg.json   ← نفس الملف!
```

**314 فيلم عربي** ماسكهم **34 ملف كاش بس**. أول ما السكربت يملأ
الملف، كل العناوين التانية بتقرأ نفس السجل:

> **أحمد و أحمد** ← المخرج: **عمرو عرفة**، الأبطال: **سامح حسين**…

**الإصلاح:** `tools/lib/cachekey.js` بيحافظ على حروف كل الأنظمة
وبيضيف **hash** قصيرة من العنوان الأصلي، فالعنوانين اللي بيتطبّعوا
لنفس النص بيفضلوا في ملفات مختلفة.

**الإصلاح بطبّق على 689 سجل** في 4 رفوف (`arabic-films`,
`arabic-series`, `cartoon-series`, `turkish-series`) — اتمسحوا
واتعاد بناؤهم من الأول بدل ما نصلّحهم باليد. البحث اليدوي (اللي
مش متكتوب جنبه `source`) **ماتمسش**.

الاختبار `tools/test-cachekey.js` بيتأكد إن العناوين العربية
الماصدفة دي فعلاً كل واحد فيهم بياخد ملف مختلف.

## IMDb: الفهرس المحلي والبحث المباشر

IMDb ينشر الكتالوج بتاعه **ملفات TSV مجانية** من غير مفتاح:
`title.basics` (1.1GB) و `title.akas` (517MB) و `title.ratings` (9MB).

### أداة بحث مباشرة — دي الحاجات المفيدة فعلاً

```bash
node tools/imdb-lookup.js --type tvSeries "Payitaht Abdülhamid"
node tools/imdb-lookup.js "Ahmed bin Hanbel" "Tayyar Sabah"
node tools/imdb-lookup.js --file titles.txt
```

بتدور في الكتالوج كله **أوفلاين** — من غير شبكة ومن غير حد للطلبات.
دي أداة البحث اليدوي: بتقول "هل المسلسل ده موجود في IMDb أصلاً؟" و
"إيه اسمه الحقيقي؟" — وده اللي بيحل المجلد اللي اسمه عربي والمقال
اللي اسمه تركي.

### الفهرس

```bash
node tools/build-imdb-index.js   # ~10 دقايق، بيقرا 1.6GB
node tools/imdb-ranks.js         # أعداد الأصوات لكسر التعارض
```

**16,387** مدخل طابقوا عنوان من المكتبة.

### ليه الفهرس **مش** متوصّل بصفء التعبئة

`tools/lib/imdb.js` موجود ويشتغل، بس **مtyreiqش** في `fill-media`.
السبب: بيوصل **20 عنصر من 244 ناقص**، وجزء منهم **غلط**:

| المجلد | طلع عنده | الصح |
|---|---|---|
| `Carter` | Kateo (2022) | Carter (2020) |
| `Sinbad` | Szindbád (1971) | sinbad كامل |
| `Edge Of Extinction` | The Brink (2020) | (2023) |
| `US` | Us (1991) | Us (2019) ✅ |

التصويت **مش** بيحل التعارض: `Carter` بياخد فيلم تركي لأنه
عنده 11,009 صوت. الإشارة الصح هي **العنوان الأصلي** — الشغل اللي
اسمه الأصلي "Kateo" مش اللي مجلد اسمه `Carter` بيقصده.

الحارس المضاف: العنوان من **كلمة واحدة** لازم يكون عنوانه الأصلي
نفس الكلمة. ده بيخلّي `Klaus` و`Hop` و`Us` يوصلوا صح.

### خلل تقني اتصلّح:_ws.unshift على stream

```js
// غلط: بعد ما الـlistener يشتغل، الـstream بيفضل في flowing mode
// وأي بيانات اتقرت قبل ما readline يتركّب بتضيع
raw.once("data", (c) => { raw.unshift(c); resolve(); });
```

النتيجة: **12.8 مليون سطر اتقروا، صفر مطابقات** — الهيدر مانقراش،
فكل سطر اتزحزح عمود، و`primaryTitle` بقى `undefined` دايمًا. الحل إن
الحBake يتقري من **handle تاني**، وبعدين stream جديد.

## Wikidata كـ "مصدر الحقول الناقصة"

المشكلة الحقيقية مكانش السجلات الناقصة — كانت **السجلات الرفيعة**.
كان في 282 فيلم عربي شغّال من غير مخرج ولا أبطال، و **1019 لعبة من
غير مطور ولا تصنيف**. Wikidata موجود بالظبط عشان ده.

بيشتغل على قسمين:

| القسم | إيه اللي بيعمله |
|---|---|
| **ENRICH** | يملأ الحقول الفاضية في سجل موجود — **2237 سجل** |
| **FILL** | بيعمل سجل جديد للعناصر اللي مفيش لها أي سجل — **326 عنصر** |

مش بيكتب فوق أي حاجة موجودة، والبحث اليدوي (`source` فاضي) مش
بيتلمس خالص.

#### حمايات Wikidata — كل واحدة بسبب خطأ حقيقي

| الحارس | يمنع إيه |
|---|---|
| **الوسيط لازم يطابق** | رف الأفلام ياخد مسلسل، ورف الأنمي ياخد الـمانجا |
| **الكلمات العربية تتطابق بعد التجفيف** | `جنية` = `جنيه` ✅ لكن `المصيد` ≠ `المصيدة` ❌ |
| **عدد الأرقام** | `11.11` (رقمين) مش `11-11-11` (3 أرقام) |
| **أول نتيجة بتفضل** | `Dragon 3` لازم ياخد الجزء التالت مش 2010 |
| **الاسم المكسور** | `BlackClover` → `Black Clover` |
| **لغة الرف** | `122` فيلم مصري، والعنوان أرقام فمفيش لغة منه |

#### نقطة مهمة عن `\b`

الكلمات الدالة لازم تتقسم لأنظمة كتابة مختلفين:

```js
// غلط: \b مش بيشتغل مع العربي
/\b(?:film|فيلم)\b/i     // "فيلم" مش بتتطابق أبداً

// صح
/\b(?:film|movie)\b/i    // لاتيني
/(?:فيلم|فلم|مسلسل)/     // عربي — من غير \b
```

في JavaScript الـ`\b` معرّف مقابل `[A-Za-z0-9_]` بس، فمفيش حد
كلمة قبل حرف عربي أو ياباني. ده كان بيسبّب إن **كل** عنوان عربي
يتعامل كأنه مش موجود.

## ملاحظات عن rate limits

- كل مزود بيبعت **طلب واحد كل فترة** (Steam 1.2s، Wikimedia 1.4s).
- **ممنوع تشغيل أكتر من job مع بعض على نفس الـ IP.** اتنين
  `fill-media` مع بعض أو `fill-media` مع `fill-games` بيقسّموا
  نفس الحصة من ويكيبيديا، والرد بيبقى 429.
- **الفرق بين "مفيش نتيجة" و"محدش سأل"**: `getJson` بيرجع `null`
  لما مفيش صفحة، وبيعمل **throw** لو الرد 429 / 5xx / فشل الشبكة.
  الـ fill scripts بيعيدوا المحاولة في الحالة التانية، وما بيسجّلوا
  حاجة كـ miss إلا لو البحث اتعمل فعلاً. من غير ده كان تشغيل
  متوازي بيسجّل مئات الأفلام كـ "مش موجودة" وهي موجودة.
- لو شفت `transient retries` في الخاتمة، ده معناه فيه ضغط على
  المصدر — استنى شوية قبل الجولة اللي بعدها.

## تنظيف السجلات

السكربتات **بتضيف أو تستبدل** السجل، فمحدش بيمسح سجل قديم. لو
اتغير مسار مزود لATEGORY، السجلات القديمة بتفضل موجودة:

```bash
node tools/drop-stale.js --dry   # بيشوف هيحذف إيه
node tools/drop-stale.js         # ينفّذ
```

بيشيل أي سجل مصدره مش مسموح به في القايمة بتاعته (مثلاً
`foreign-film-series` مفعليش يقبل سجل من `tvmaze`، لأن القايمة
أفلام مش مسلسلات). السجلات اللي متكتبتش `source` — يعني البحث
اليدوي — **مش بتتلمس**.
